# Система поддержки принятия решений (СППР)

Творческое задание по дисциплине «Рекомендательные системы и системы поддержки принятия решений», тема 7 «Разработка системы ППР».

Авторы: _ФИО участников_

Веб-приложение сравнивает альтернативы по нескольким критериям и выдаёт рейтинг тремя методами:

| Метод | Что делает |
|---|---|
| AHP (метод Саати) | Веса критериев по матрице парных сравнений, проверка согласованности CR < 0,1, итоговая оценка альтернатив |
| TOPSIS | Близость альтернативы к идеальному решению с весами из AHP |
| ELECTRE I | Индексы согласия и несогласия, отношения превосходства, чистый индекс для ранжирования |
| Парето | Отметка недоминируемых альтернатив |

## Демонстрация

Файл [`demo.ipynb`](demo.ipynb) по шагам показывает работу всех методов на варианте 1: матрицу парных сравнений, веса, λmax, CI и CR, сверку с примером из методички, оценки AHP, расчёт TOPSIS (D⁺, D⁻, C), матрицы согласия и несогласия ELECTRE I, отношения превосходства, чистый индекс, Парето, сводный рейтинг, графики, проверку чувствительности и чтение своего CSV. GitHub показывает блокнот вместе с результатами, запускать его не нужно.

## Запуск

```bash
pip install -r requirements.txt
streamlit run app.py
```

Приложение откроется в браузере по адресу http://localhost:8501.

## Как пользоваться

1. Слева выбрать пример из курса (вариант 1-10) или загрузить свой CSV.
2. Вкладка «Данные и критерии»: выбрать критерии и направление (больше = лучше или меньше = лучше).
3. Вкладка «Веса критериев (AHP)»: задать важность баллами или попарными сравнениями по шкале Саати. Приложение покажет веса, λ max, CI и CR.
4. Вкладка «Рейтинг»: места по трём методам, графики, корреляция Спирмена, матрицы ELECTRE. Рейтинг можно скачать в CSV.

## Формат CSV

Первый столбец: названия альтернатив (без повторов). Остальные столбцы: числовые значения критериев больше нуля. Подходит и CSV из русского Excel (разделитель «;», дробная часть через запятую). Направление можно указать в названии столбца:

```
Альтернатива,Цена (min),Качество (max)
A,100,7
B,120,9
```

## Данные примера

Файл `data/variants.csv` содержит все 10 вариантов бизнес-проектов из файла практики «Метод Саати_stud.xls» (лист «Варианты»); номер варианта в первом столбце. Качественные оценки переведены в баллы:

| Критерий | Баллы |
|---|---|
| Готовность (max) | идея 1, технология 2, прототип 3, поток 4, налажено 5 |
| Конкурентная среда (max) | агрессивная 1, сильная 2, нейтральная 3, нет 4, неопределено 1 |
| Потенциальный рынок (max) | малый 2, VIP 2, средний 3, прогноз недостоверный 1, неопределен 1 |
| Популярность (max) | недостоверно 1, кратковременный всплеск 2, средняя 3, высокая долговременная 4 |
| Риски (min) | низкие 1, умеренные 2, средние 3, высокие 4, недостоверные 5 |

Недостоверный прогноз получает худший балл: лицо, принимающее решение, считается осторожным.

## Формулы

- AHP: вес критерия = среднее геометрическое строки матрицы, делённое на сумму; λ max = Σ (сумма столбца × вес); CI = (λ max − n) / (n − 1); CR = CI / ПСС.
- Локальный приоритет AHP: для max x / Σx, для min (1/x) / Σ(1/x).
- TOPSIS: r = x / √Σx², v = w × r, C = D⁻ / (D⁺ + D⁻).
- ELECTRE I: C(a,b) = сумма весов критериев, где a не хуже b; D(a,b) = наибольший проигрыш a, делённый на размах критерия; a превосходит b, если C ≥ порога согласия и D ≤ порога несогласия.
